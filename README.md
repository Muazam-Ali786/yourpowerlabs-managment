# ⚡ YourPower Labs — Expense Tracker

## Run karo
```
cd backend
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
uvicorn main:app --port 3000
```
Phir `frontend/login.html` browser mein kholo.

## Login
- **Admin:** Admin / Admin123

## Features
- Admin: Debit + Credit | User: Sirf Debit
- Per-user budget
- Receipt/bill upload (optional)
- Carry forward balance
- Weekly / Monthly / Yearly PDF
- Dark / Light mode
- Auto logout (15 min)
- Fully responsive
